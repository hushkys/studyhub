o Operacní sysém
* U IP adresy tzv. Logická adresa, která je napevno svázaná s maskou síte
* Z pohledu sítového adaptéru ješte na MAC adresu
* Psaná desítkove, ve dvojkové soustave tzv binární
* Skládá se z HOST ID (Unikátne identifikuje konkrétní zarízení (hostitele) v rámci dané síte) a NET ID (Urcuje, do které síte zarízení patrí. Všechna zarízení ve stejné lokální síti mají stejné Net ID), hranice mezi nimi je urcena jednickami z masky síte
* Když zarízení pošle data, sítový router se podívá na Net ID, aby zjistil, na kterou sít je má poslat. Až v cílové síti se data dorucí zarízení s príslušným Host ID.
* Delí se na trídy A, B, C
* Má 32 bitu
* Delí se na privátní a verejnou
* Privátní se využívá v lokálních sítích, v rámci jedné síte musí být jedinecná, ale muže se opakovat v ruzných oddelených sítích
* Verejná je viditelná v internetu a zcela jedinecná
 
DHCP server
* Protokol z rodiny TCP/IP
* Používá se pro automatickou konfiguraci pocítacu pripojené do síte
* Prideluje IP, masku, default gateway a adresu DNS serveru
* Princip 
o Po pripojení do síte klient vyšle broadcastem DHCPDISCOVER packet
o DHCP odpoví DHCPOFFER s nabídkou IP adres
o Klient si vybere a požádá o ni DHCPREQUEST
o Server potvrdí DHCPACK
o Po obdržení muže klient IP používat
o Klient musí obnovit svou IP adresu pred ubehnutím lhuty, aby ji mohl nadále používat
DNS
* Delí se na 3 servery
o Autoritativní - ukládá záznamy pro danou sít
o Chache - ukládá všechny záznamy které vy jako klient potrebujete preložit
o Root name - nejvyšší, spadají do tzv top level domain, jsou oznacovány písmeny A - M, obsahují všechny záznamy prekladu, je jich 13
* Prekládá doménové jméno (napr seznam.cz) na IP adresu, citelnou pro pocítac
 
Subnety - podsíte
* Samostatná cást pocítacové síte
* Obvykle mínena konkrétní vyclenená cást vetší IP síte
* Pro urcení rozsahu IP adres v dané podsíti slouží maska síte
 
Maska síte
* Pomocí masky router rozhoduje o smerování IP datagramu
* Zapsaná v binárním tvaru
* Maska 255.255.255.0 muže být tedy zapsána 11111111.11111111.11111111.00000000
* V základu jde o dve cásti, prefix identifikující sít a adresa uzlu v rámci podsíte
