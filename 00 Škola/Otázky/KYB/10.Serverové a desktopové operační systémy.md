	- Linux
		- /kořen souborového systému (C:\ U Windowsu)
		- /bin zákl. spustitelné soubory pro použití všemi uživateli (C:\Windows\system)
		- /boot - zde je umístěno jádro (kernel) systému a jeho mapa, initrid, soubory zavaděče (boot loader) GRUB (C:\Windows\System)

		- /lib - zakladni sdilene knihovny systemu, mapovani klavesnice s konzolove fonty, moduly pro jadro systemu(kernel) (C:\Windows\System32\)

		- /proc -soubory nastaveni a stavu systemu a jednotlivych procesu - dalo by se rict, ze je to mapa stavu pameti RAM (Task manager - spravce uloh)
		- /root - domovsky adresar superuzivatele (root) budu predstirat ze jsem pochopil co prave rekl a delat ze to je hrozne zajimava informace 
		- /sys - virtualni adresar (jadra 2.6.x)
		- /tmp; /temp - adresar pro odkladaci a pomocne soubory (C:\Windows\temp\; C:\users\jmeno\appdata\local\temp)
		- /usr - dalsi stromova struktura, obsahuje velke mnozstvi informaci, jako knihovny, zdrojove kody, spustitelne soubory, konfiguracni soubory a dalsi. nejdulezitejsi z nich jsou: (C:\users\jmeno\appdata)
		- /var - soubory, jejichz obsah se behem chodu systemu vetsinou meni; dejdulezitejsi jsou:**/VAR/WWW** webove stranky webserveru (C:\Windows\system32\; C:\Windows\system\)

### Serverový OS
- serverový operacni system je mimoradne propracovany OS s podporou pro vice klintu. Diky funkcim a moznostem pozadovanym v architekture klient-server nebo podobnem firemnim vypocetnim prostredi je to propracovanejsi OS.
- **Vlastnosti operačního systému Server**
	- pokročilé funkce pro provoz, správu, monitorování a řízení procesů, programů a klientských zařízení – jako jsou různé servery, jako jsou webové, souborové, aplikační, poštovní a databázové servery – jsou poskytovány serverovým OS
	- s tímto systémem můžeme propojit několik klientů s jedním serverem a poskytovat jim služby
	- účelem server OS je pracovat na serveru a jeho zpracovatelská kapacita je vyšší.
	- Server OS pojme větší bezpečnost než kterýkoliv jiný operační systém
- **Příklady serverového OS**
	- Windows server: obrovské množství spravovatelncýh úložišť
	- Tradiční server: Malé a střední podniky s malou uživatelskou základnou.
	- Webový server: systém, který poskytuje klientům přístup k webovým stránkám programovaným HTML. V reakci na požadavky z prohlížečů zpracovává systém a poskytuje data, včetně HTML stránek a obrázků.
	- Adresářový server: využívá adresář, který je užitečná pro OS Linux a UNIX
	- Blade server: pojme stovky blade serverů a je prostorově efektivnější nebo levnější než servery namontované do racku.
	- Databázový server: jedná se o počítačové servery, které se používají k ukládání dat a nabízení služeb jiným zařízením nebo softwaru.
