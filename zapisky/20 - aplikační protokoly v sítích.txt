Mail server
· Protokol IMAP, POP3 a SMTP
· RFC - technické dokumentace k protokolu
o POP3 – 5034
o IMAP – 3501
o SMTP – 5321
 
Protokoly:
 
POP3
· Protokol pro stahování elektronické pošty do PC
· Jedná se o úplně nejstarší protokol, který funguje vždy na poštovním serveru v základní konfiguraci
· Port 110 (nešifrovaný)
· Port 995 (šifrovaný)
· Protokol vždy po připojení k serveru stahuje (ve standartním módu) el. poštu ze složky new
 
IMAP
· Poslední verze IMAP4
· Je navržen tak, aby synchronizoval poštu
· Nějaký složky new a cur (current)
· Vždy je potřeba přístup k internetu
· Musí se dokonfigurovat nebo zapnout
· Port 143 (nešifrovaný)
· 993 (šifrovaný)
 
 
SMTP
· Šifrovaný port 465 a 587
· Nešifrovaný port 25
· Protokol byl navržen jen na odchozí poštu
· Pouze pro odchozí poštu narozdíl od imapu a pop3
 
MUA
· Mail User Agent
· Jedná se o poštovního klienta který zprostředkovává komunikaci mezi uživatelem a poštovním serverem (IMAP – synchronizace), a mezi klientem a počítačem a uživatelem POP3)
· Outlook, tenderbird?
MTA
· Mail Transfer Agent
· Slouží pro přesun pošty mezi servery a mezi serverem a počítačem
MDA
· Mail Delivery Agent
· Slouží k doručení pošty do příslušné poštovní schránky
· Dovecot
 
FTP
· Jedná se o jeden z nejstarších protokolů pro přenos souborů mezi dvěma počítači (server-klient)
· Protokol klient server
· Klientskou část tvoří tvz FTP klient – filezilla totalcommander, příkazový řádek a nebo webový prohlížeč
· Serverovou část tvoříme pomocí FTP serveru – ceasar, filezilla
· Pro přihlášení je zapotřebí hostitel (název serveru, IP) a přihlašovací údaje
· Porty 20 a 21 (nešifrovaný)
· Port 20: slouží k přenosu dat
· Port 21: příkazy
· Porty 989 a 990 (šifrované)
Protokol SFTP 
· Šifrování probíhá pomocí SSH
· Port 989
Protokol FTPS
· Pomocí SSL a TLS
· Port 990
 
Přenos webových stránek s klienta na server (celkově FTP)
 
HTTP
· HTTP je internetový protokol určený původně pro výměnu hypertextových dokumentů ve formátu HTML.
· Pomocí rozšíření MIME, umí HTTP přenášet jakýkoli soubor (podobně jako e-mail), používá se společně s formátem XML pro tzv. webové služby
· Protokol funguje způsobem dotaz-odpověď. Uživatel (pomocí programu, obvykle internetového prohlížeče) pošle serveru dotaz ve formě čistého textu, obsahujícího označení požadovaného dokumentu, informace o schopnostech prohlížeče apod. Server poté odpoví pomocí několika řádků textu popisujících výsledek dotazu
· port TCP/80
· K protokolu HTTP existuje také jeho bezpečnější verze HTTPS (port 443), která umožňuje přenášená data šifrovat a tím chránit před zneužitím.
