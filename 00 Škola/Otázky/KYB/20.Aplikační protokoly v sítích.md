POP3 
- nejstarší poštovní protokol, který funguje defaultně na poštovních serverech
- protokol automaticky stahuje poštu z poštovního serveru do klientské aplikace, ze serveru se pošta maže (záleží na konfiguraci)
IMAP4
- synchronizuje poštu s poštou v klientské aplikaci (v poštovním klientu) se serverem
- synchronizace probíhá pomocí hlaviček a je vyžadováno stálé připojení k internetu

### Poštovní protokoly
##### SMTP
(Simple Mail Transfer Protocol)
- Posílání e-mailů mezi servery a z klienta na server. Funguje jako poštovní doručovatel
- odesílá e-maily ze zařízení přes MUA/MTA a dál mezi MTA servery.
- Neposkytuje čtení pošty, jen přenos
- porty:
	- 25 nešifrovaná komunikace
	- 587 šifrovaná (za použití STARTTLS)
- **Kdy se používá:** Outlook, Thunderbird, Gmail při odesílání zprávy.
##### POP3
(Post Office Protocol v3)
- Stáhne e-maily z poštovního serveru do klienta a většinou smaže ze serveru.
- Je jednoduchý, ale když si stáhneš poštu z jednoho zařízení, na jiném ji neuvidíš.
- **Kdy se používá:** když chci mít poštu offline a nepotřebuji synchronizaci.
##### IMAP4
(Internet Message Access Protocol)
- Drží poštu na serveru a jen synchronizuje to, co vidím v klientu.
- Mohu mít víc klientů (mobil, PC...) a stav (přečtené, smazané...) se všude projeví
- Funguje **jen** online, protože pořád komunikuje se serverem
- **Kdy se používá**: Když používáš poštu na více zařízeních a chceš stejný inbox všude.
##### MUA, MTA, MDA
(to už nejsou protokoly)
- MUA (Mail User Agent): emailový klient (Outlook, Gmail app)
- MTA (Mail Transfer Agent): server/[démon](https://cs.wikipedia.org/wiki/D%C3%A9mon_(software)) co předává poštu mezi servery.
- MDA (Mail Delivery Agent): konečný doručovatel do mailboxu
- Think of it like poštu:  
	📨 Ty = MUA → 📨 pošta jde na server → 🚚 MTA ji veze přes net → 📬 MDA ji dá do cílový schránky.
#### Další aplikační protokoly
##### HTTP
(Hypertext Transfer Protocol)
- protokol, co dělá web FUNKČNÍ - přenáší webové stránky mezi browserem a serverem.
- porty:
	- http → 80
	- https → 443
- **K čemu to je dobrý**: posílá GET/POST požadavky, server odpovídá s HTML/JSON
##### FTP
(File Transfer Protocol)
- Slouží k přenosu souborů mezi klientem a serverem
- Má samostatné spojení pro řízení a pro samotná data
- Není šifrovaný (proto se často používá FTPS/SFTP)
##### DNS
(Domain Name System)
- Překládá doménová jména (např. google.com) na IP adresy
- Bez toho bych si musel pamatovat dlouhá IPčka místo názvů
##### DHCP
(Dynamic Host Configuration Protocol)
- Automaticky přiděluje IP adresy a síť. info zařízení při připojení k síti.
- Zkracuje konfiguraci — žádné manuální nastavování IP
- **K čemu**: Jakmile se tvůj laptop připojí k Wi-Fi/routeru

**RYCHLEJ TAHÁK**

| Protokol       | Co dělá                                | Typicky používá                |
| -------------- | -------------------------------------- | ------------------------------ |
| **SMTP**       | Odesílá emaily mezi servery/od klienta | Odesílání emailů               |
| **POP3**       | Stáhne emaily ze serveru (a smaže je)  | Jednoduchý download pošty      |
| **IMAP4**      | Synchronizuje poštu _na serveru_       | Více zařízení                  |
| **MUA**        | Emailový klient                        | Čtení/posílání                 |
| **MTA**        | Přeposílá emaily mezi servery          | Emailový server                |
| **MDA**        | Doručuje email do mailboxu             | Lokální doručení               |
| **HTTP/HTTPS** | Přenáší webové stránky                 | Web browsing                   |
| **FTP**        | Přenáší soubory                        | File upload/download           |
| **DNS**        | Překládá domény na IP                  | Adresní look-up                |
| **DHCP**       | Dává IP adresy                         | Automatická síťová konfigurace |
